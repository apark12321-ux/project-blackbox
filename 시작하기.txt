1. v10에서 v11로 바꾸는 작업이라 기존 layout-client.tsx가
   있으면 빈 파일로 만들거나 지워야 합니다.
   → v11은 layout-client.tsx 사용 안 함.
   → 각 페이지가 V11Shell로 감쌈.

2. 만약 빌드 실패하면 (특히 layout-client 관련):
   frontend/app/layout-client.tsx를 이 내용으로 교체:
   
   'use client';
   export default function LayoutClient({ children }: any) {
     return <>{children}</>;
   }

3. 환경변수는 Railway/Vercel에 이미 설정됨. 건드리지 마세요.
