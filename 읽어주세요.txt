=============================================
  AlgoMaker v9 · 6단계 플로우 완성판
=============================================

🎯 업데이트 내용

▪ 랜딩 페이지 컨셉("키워드 하나면 완성까지 6단계")에 맞춰
  전체 플로우를 6단계로 복원

  1. 키워드 발굴 (/keyword)   ← 새로 추가
  2. 뉴스 큐레이션 (/news)    ← 새로 추가
  3. AI 대본 작성 (/script)
  4. TTS + 영상 합성 (/studio)
  5. 수익화 검증 (/publish)
  6. 완료 (/done)

▪ 각 단계 모두 /plan 스타일 (다크 + 골드 + 채팅형 UI) 통일

▪ 예전 /create, /plan 주소는 자동으로 /keyword 로 리다이렉트

▪ 시니어 모드, 자유 이동, "← 이전" 버튼 그대로 유지

---

📋 배포 방법

1. ZIP 압축 풀기
2. project-blackbox-update 폴더 열기
3. "frontend" 와 "infra" 폴더 복사
4. 문서 > GitHub > project-blackbox 에 붙여넣기 → "모두 예"
5. GitHub Desktop:
   - Summary: v9 6단계 플로우 완성
   - Commit to main → Push origin
6. 5~7분 대기
7. project-blackbox-cpqy.vercel.app/keyword 접속 → Ctrl+Shift+R

🎬 확인 포인트

랜딩(/) → "무료로 시작하기" 클릭 → /keyword 로 진입

1. /keyword — 카테고리 클릭 → 키워드 목록 → "뉴스 수집 →"
2. /news    — 기사 선택 → "대본 만들기 →"
3. /script  — 6블록 대본 + 채팅 수정 → "영상 만들기 →"
4. /studio  — TTS → 자료화면 → 아바타 → 자막 → 합성 → "배포하기 →"
5. /publish — SEO 최적화 + YouTube 업로드 시연 → "완료 →"
6. /done    — 축하 + "새 영상 만들기"

상단 StepBar에서 언제든 자유 이동 가능.
오른쪽 [일반/👥시니어] 토글로 시니어 모드 전환.
