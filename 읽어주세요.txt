=============================================
  AlgoMaker v8 전체 플로우 · 배포 방법
=============================================

🎯 해야 할 일은 딱 하나!

이 폴더 안의 "frontend"와 "infra" 폴더를
GitHub 폴더에 그대로 덮어쓰기만 하면 끝입니다.

---

📋 방법 (3분)

1. 이 ZIP 파일의 압축을 풉니다.
   → "project-blackbox-update" 폴더가 생깁니다.

2. 그 안에 있는 두 폴더를 복사합니다:
   - frontend
   - infra

3. 윈도우 탐색기에서 다음 경로로 이동:
   📂 문서 > GitHub > project-blackbox

4. 여기에 복사한 두 폴더를 붙여넣기 합니다.
   → "이미 있는 파일을 덮어쓰시겠습니까?" 창이 뜨면
   → "모두 예" 클릭!

5. GitHub Desktop 실행
   → 왼쪽에 14~15개 변경 파일이 보입니다
   → Summary에 입력: 전체 플로우 v8 완성
   → [Commit to main] 클릭
   → 상단 [Push origin] 클릭

6. 5~7분 기다리기 (Vercel + Railway 자동 배포)

---

✅ 배포 확인

https://project-blackbox-cpqy.vercel.app/plan
접속해서 Ctrl+Shift+R 새로고침.

"대본 만들기 →" 버튼 누르면 /script 페이지로 이동하고,
"영상 만들기 →" 누르면 영상 제작 시뮬레이션,
"배포하기 →" 누르면 YouTube 업로드 시연,
완료 후 "새 영상 만들기"로 다시 /plan 으로 돌아옵니다.
