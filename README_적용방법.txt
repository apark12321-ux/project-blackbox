🆕 v5.2.1 변경 사항

[1] 메인 페이지 흐름 - 6단계 → 3단계!

   Before (6단계):
   홈 → /create → /keyword → /configure → /processing → /publish
   
   After (3단계):
   홈 (키워드 입력) → 자동 분야 감지 → /publish 직행
   
   * /create, /keyword, /configure 4단계 자동 생략!
   * 키워드 자동 분야 감지 (detectCategoryFromKeyword)
   * 부동산/영어/다이어트 등 11개 카테고리 자동 매칭
   
[2] 쿠키 배너 - "설정 / 모두 허용" 변경
   
   Before:
   [거부] [동의하기]  
   
   After:
   [설정] [모두 허용]
   
   효과: "단일 허용 유도" - 박 대표님 의도대로
   - "거부"는 부담스러움 → "설정"으로 부드럽게
   - 사용자가 "설정" 누르면 세부 모달로 안내
   - 대부분 "모두 허용" 선택 가능성 ↑

[3] 쿠키 설정 모달 (NEW!)
   
   "설정" 버튼 클릭 시 표시되는 다이얼로그:
   
   ┌─ 🍪 쿠키 설정 ────────────────┐
   │ 사용하실 쿠키 종류를 선택해주세요.   │
   │                              │
   │ 필수 쿠키           [필수]    │
   │ 사이트 작동에 반드시 필요          │
   │                              │
   │ 분석 쿠키          [● ─ ○]   │
   │ 사이트 사용 패턴 분석            │
   │                              │
   │ 광고 쿠키          [● ─ ○]   │
   │ 맞춤 광고 (Google AdSense)    │
   │                              │
   │ [취소]    [저장하기]            │
   └──────────────────────────────┘
   
   - 토글 스위치 (코랄 컬러)
   - 항목별 세부 설명
   - 분석/광고 개별 선택 가능
   - 저장하기 → 선택대로 적용

🎨 사용자 경험 개선

[Before - 박 대표님 지적]
홈 → 분야 선택 → 키워드 입력 → 시나리오 선택 → 처리 → 결과
= 6단계 클릭, 답답함

[After - C안 적용]
홈에서 "부동산" 입력 + 시작 클릭 → 즉시 결과
= 1번의 클릭으로 결과 도달
= 박 대표님 비전 "키워드만 입력하면 1분 안에 끝" 100% 실현

[기존 흐름 유지 (선택지)]
- 빈 키워드로 "바로 시작" → 기존 6단계 흐름 그대로
- 카테고리부터 정하고 싶은 사용자 위함
