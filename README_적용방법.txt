🎯 새 5단계 스토리보드

[STEP 1] ✏️ 제목 선택 (보라 #534AB7)
   - 3개 중 1개 클릭해서 선택
   - 알고리즘 분석 CTR 예측
   - 기본 펼침 ✓

[STEP 2] 🎬 떡상 시나리오 7단계 (코랄 #993C1D) ★ 메인!
   - 영상 대본 흐름 7단계
   - 각 시퀀스 = 헤드/목적/대본/액션/팁
   - 1분 쇼츠 버전 별도 박스 (보라 그라디언트)
   - 기본 펼침 ✓
   - "📋 전체 7단계 대본 한 번에 복사" 버튼

[STEP 3] 🎨 영상 제작 (청록 #0F6E56)
   - 시퀀스별 4종 프롬프트 (KR이미지/EN이미지/KR영상/EN영상)
   - 일관된 영상 가이드 (NotebookLM + Pinterest)
   - 기본 접힘 (필요할 때 펼치기)

[STEP 4] 🏷️ 메타데이터 (앰버 #854F0B)
   - 영상 설명 (SEO 최적화)
   - 태그 (YouTube 태그용 - 띄어쓰기 유지)
   - 썸네일 콘셉트 3가지
   - 기본 접힘

[STEP 5] 📲 SNS 업로드 (블루 #185FA5)
   - 4개 플랫폼 탭 (YouTube/쇼츠/틱톡/릴스)
   - 각 플랫폼별 제목 + 해시태그 + 캡션
   - 해시태그 자동 변환 (띄어쓰기 X + #)
   - 기본 접힘

🎨 새 UX 핵심 변화

[변화 1] 시나리오를 메인 콘텐츠로 격상
   Before: video-prompts 탭 안에 숨겨짐
   After: STEP 2로 메인 위치 + 기본 펼침

[변화 2] 단계별 펼치기/접기 (아코디언)
   - 한 번에 보이는 정보량 ↓
   - 필요한 것만 펼쳐서 확인
   - "📂 전체 펼치기" / "📁 전체 접기" 토글
   - STEP 1, 2 기본 펼침 / STEP 3, 4, 5 접힘

[변화 3] 색상 구분으로 시각적 흐름
   STEP 1: 보라 (시작)
   STEP 2: 코랄 (메인 - 박 대표님 브랜드 컬러)
   STEP 3: 청록 (창작)
   STEP 4: 앰버 (정리)
   STEP 5: 블루 (배포)

[변화 4] 5개 탭 → 5단계 스토리텔링
   Before: youtube-long / youtube-shorts / tiktok / reels / video-prompts
   After: 제목 → 시나리오 → 영상 → 메타 → SNS (자연스러운 흐름)

[변화 5] 헤더 강조
   - "✨ AI 추천 완료" 배지
   - "[키워드] 영상 자료가 준비됐습니다"
   - "아래 5단계 순서대로 따라가시면 됩니다" 가이드

[변화 6] 완료 박스 추가
   - 페이지 끝에 그라디언트 박스
   - "🎉 모두 완료했어요!"
   - "🎬 다른 영상 만들기" / "📚 노하우 보기" CTA
