📌 이번 업데이트 (v3.2.1 → v3.2.2):

✨ 신규: 다중 백업 API 전략

기존: 1번 시도 → 실패 시 동일한 모델로 1회 재시도
변경: 3단계 백업 전략

  1차 시도: 선택한 모델 (Flux 등) ─────┐
                                       │
  실패 시 (2초 대기) ───────────────────┤
                                       │
  2차 시도: Turbo 모델 (빠른 응답) ─────┤
                                       │
  실패 시 (2초 대기) ───────────────────┤
                                       │
  3차 시도: 기본 엔드포인트 (모델 미지정) ─┘

→ 첫 번째 이미지 안 나오는 문제가 거의 발생하지 않음!
→ Pollinations 콜드 스타트도 3번째 시도에서는 거의 깨어남

✏️ 수정사항:
- /imagegen 안내 문구 수정
  "이미지 생성하기" → "🎨 이미지 생성" / "🎨 썸네일 만들기"
  (실제 /publish 버튼명과 일치)
  
- 에러 메시지 개선
  "오류: 시간 초과" → "시간 초과 (Turbo 모델로 재시도)"
  사용자가 진행 상황을 알 수 있게
