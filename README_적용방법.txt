🆕 v6.0.0 변경사항 (Phase 1)

[1] 떡상 영상 사례 데이터베이스 (NEW!)
    contentEngine.ts에 추가:
    - 9개 도메인 × 3가지 패턴 = 27개 사례
    - 각 사례별 정보:
      * 패턴 이름 (예: "시간 압축형")
      * 영상 길이 추천
      * 핵심 후크 (첫 3초)
      * 떡상 이유 (패턴 분석)
      * 예시 키워드
      * 핵심 요소
    
    함수:
    - getViralCases(categoryId, count) - 도메인별 사례
    - getFeaturedViralCases() - 메인 갤러리용
    
    ⚠️ 박 대표님 원칙 100% 준수:
    - 채널명/사람이름 X
    - 자극적 수익 표현 X
    - "왜 떡상했는가" 패턴 분석 중심

[2] 메인 페이지 - 떡상 사례 갤러리 섹션 (NEW!)
    위치: 9개 분야 매트릭스 다음
    구성:
    - "🔥 실제 떡상 패턴 분석" 빨강 배지
    - 헤드라인: "분야별 떡상 영상 패턴"
    - 9개 카드 그리드 (도메인별 대표 사례 1개씩)
    - 각 카드:
      * 이모지 + 분야 + 패턴
      * 핵심 후크 (이탤릭)
      * 떡상 이유 분석
      * 영상 길이 + 핵심 요소
      * 예시 키워드
      * "→ 이 패턴으로 만들기" CTA
    - 클릭 시: /publish로 직행 (3단계 흐름)

[3] publish 페이지 - STEP 1 추가 (NEW!)
    기존 5단계 → 6단계로 확장:
    
    STEP 1 (NEW): 📺 비슷한 떡상 영상 사례
    STEP 2: ✏️ 제목 선택 (이전 STEP 1)
    STEP 3: 🎬 대본 7단계 (이전 STEP 2)
    STEP 4: 🎨 영상 제작 (이전 STEP 3)
    STEP 5: 🏷️ 메타데이터 (이전 STEP 4)
    STEP 6: 📲 SNS 업로드 (이전 STEP 5)
    
    STEP 1 내용:
    - 도메인별 떡상 사례 3개
    - 각 카드:
      * 이모지 + 패턴 + 영상 길이
      * 핵심 후크 (강조)
      * 왜 떡상했을까 (패턴 분석)
      * 핵심 요소
    - 사용자 키워드와 같은 분야의 사례 자동 매칭

[4] AI 이미지 미리보기 (NEW!)
    위치: STEP 3 (대본 7단계) 각 시퀀스 카드
    구성:
    - "🎨 이 장면 AI 이미지 미리보기" 라벨
    - 16:9 이미지 영역
    - Pollinations.ai 무료 API 활용
    - 시퀀스별 자동 다른 시드 → 다른 이미지
    - lazy loading으로 성능 최적화
    - 에러 시 fallback 표시
    - 안내: "Midjourney·DALL-E로 고품질 생성 가능"
    
    ⚠️ Pollinations 무료 API:
    - URL: image.pollinations.ai/prompt/{영문프롬프트}
    - 무료 무제한
    - 실시간 생성 (5~15초 소요)
    - 광고 없음
