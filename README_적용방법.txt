🎯 7개 섹션 구조 (혹하는 흐름)

[1] HERO - 떡상 후크
   • "키워드 하나로 떡상 시나리오가 만들어집니다"
   • Story-driven (결과 먼저 보여주기)
   • 핵심 통계 3개 (proof density)
     - 100명 = 100가지 결과
     - 8개 분야 자동 인식
     - 무제한 무료

[2] 🔥 LIVE DEMO (★ 신규 - 가장 혹하는 섹션!)
   • 사용자가 즉석에서 키워드 입력
   • 실시간으로 떡상 후크 미리보기
   • 부동산 → "8천만원 차익..." 즉시 표시
   • "와! 진짜 다르네?" 순간을 만듦

[3] BEFORE vs AFTER 비교
   • 일반 AI 글쓰기 (일기장 톤) vs AlgoMaker (떡상 톤)
   • 같은 "부동산" 키워드로 시각 비교
   • 차별점 즉시 인지

[4] 8개 분야별 트리거 매트릭스 (★ AEO 핵심)
   • 🏠 부동산 → 수치 + 시간단축
   • 🗣️ 영어 → 경험담 + 시간효율
   • 💪 다이어트 → 비포애프터
   • 📚 자기계발 → 평범인 변신
   • 🤖 AI 도구 → 무료 + 무제한
   • 👴 시니어 → 연령 가능성
   • 🍳 요리 → 쉬움 + 검증
   • ✈️ 여행 → 가성비 + 비밀

[5] FAQ (★★★ AEO 최강)
   • 6개 명확한 Q&A
   • ChatGPT, Perplexity가 인용 가능한 형식
   • Schema.org FAQPage 구조화
   • "AlgoMaker는 무엇인가요?" 등 핵심 질문

[6] HOW IT WORKS (4단계)
   • 분야 선택 → 키워드 → AI 분석 → 결과
   • 시각적 단계 표시

[7] FINAL CTA
   • 그라디언트 배경 + 큰 버튼
   • 무료/회원가입 X 강조

🔥 라이브 데모 동작 방식 (가장 강력한 차별점!)

사용자 흐름:
1. 메인 페이지 진입
2. 노란색 데모 섹션에 시선 집중
3. "예: 부동산, 영어 회화..." 플레이스홀더 보임
4. 빈 입력 시 4개 추천 키워드 표시
5. 키워드 입력 → 0.3초 후 실시간 미리보기
6. 도메인 + 트리거 + 떡상 후크 미리보기 표시
7. "와! 다르네?" → "시작 →" 버튼 클릭
8. /create로 데모 키워드 그대로 전달

매핑된 키워드 풀 (10개):
• 부동산 → 수치 중심
• 주식 → 수치 + 경험담
• 영어/영어 회화 → 경험담
• 다이어트 → 비포애프터
• AI → 무료/무제한
• 은퇴 → 연령 가능성
• 코딩 → 평범인 변신
• 요리 → 쉬움 강조
• 여행 → 가성비 + 비밀

부분 매칭 (정규식):
• /부동산|아파트|매물/ → 부동산 풀
• /다이어트|살빼기|체중/ → 다이어트 풀
• /ai|chatgpt|gpt/i → AI 풀
• 등등
