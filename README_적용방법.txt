🎨 UX 디테일

[자동 롤링]
  - 4초마다 다음 메시지로 전환
  - 페이드 + 슬라이드 업 애니메이션 (0.7초)
  - 부드러운 전환 (점프 X)

[하단 인디케이터 점]
  - 4개 점으로 현재 위치 표시
  - 활성 점: 코랄(#c65f3b) + 가로로 길게
  - 비활성 점: 연한 코랄(#fde0c5) + 원형
  - 클릭하면 해당 메시지로 즉시 전환
  - 호버하면 색상 변경

[높이 점프 방지]
  - min-height: 165px (데스크탑)
  - min-height: 200px (600px 이하)
  - min-height: 230px (480px 이하)
  - 텍스트 길이가 다를 때도 레이아웃 안정

[모바일 반응형]
  - 모바일에서도 자연스럽게 작동
  - 점 터치 가능
