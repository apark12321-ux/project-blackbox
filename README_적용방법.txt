🎬 작동 방식:

1단계: 결과 페이지 진입
  ↓
2단계: 사용 횟수 확인
  ├─ 무료 횟수 남음 → 그대로 이용
  └─ 무료 끝 → 광고 모달 표시
  
3단계 (광고 모달):
  ┌────────────────────────────┐
  │ 🎬 광고를 보고 무료로!      │
  │                            │
  │ 30초 광고 시청 →           │
  │ "결과 페이지 1회 이용" 보상  │
  │                            │
  │ [▶ 광고 시청하고 받기]      │
  │ [나중에 할게요]            │
  └────────────────────────────┘
  
4단계 (광고 재생):
  - 30초 영상 광고 (가상)
  - 5초 후 스킵 가능
  - 진행바 + 카운트다운
  
5단계 (완료):
  🎉 "광고 시청 완료!"
  → 1회 추가 사용권 부여
  → 결과 페이지 진입
