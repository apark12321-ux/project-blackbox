🚀 떡상 시나리오 엔진 v2 (가장 큰 변화)

박 대표님이 지적하신 핵심 문제들 모두 해결:

❌ 이전 (v3.6.0):
   - "[핵심 포인트 1]" 같은 빈칸 placeholder
   - 같은 키워드 = 항상 같은 결과
   - "주식가 그래요" 같은 조사 오류
   - 정보 나열식 (감동 X, 진심 X)

✅ 새로운 (v3.7.0):
   - 모든 스크립트 구체적 (placeholder 0개)
   - 매번 다른 결과 (시드 + 카운터 기반)
   - 한국어 조사 자동 처리 (받침 판별)
   - 7단계 감정 곡선 (Hook→공감→갈등→여정→클라이맥스→교훈→행동)
   - 진심 어린 화법 ("한 분 한 분 다 읽어볼게요")
   - 구체적 디테일 ("점심시간 회사 앞 공원에서", "1주일 단위로")

🔄 "다시 생성" 버튼 추가
   - /publish 페이지 상단에 버튼
   - 누를 때마다 완전히 새로운 시나리오
   - 100명이 같은 키워드 입력해도 100가지 결과

📊 시나리오 풀 규모:
   - 후크: 6개 패턴
   - 공감: 5개 패턴
   - 갈등: 5개 패턴
   - 여정: 5개 패턴
   - 클라이맥스: 5개 패턴
   - 교훈: 4개 패턴
   - 행동: 4개 패턴
   - 시간 표현 풀: 8개
   - 숫자 표현 풀: 8개
   - 감정 단어 풀: 8개
   - 일상 묘사 풀: 7개
   = 조합 수 수만 가지

🚫 임의 광고 영역 모두 제거 (AdSense 승인 전)

박 대표님 요청 반영:
- AdSense 환경변수(NEXT_PUBLIC_ADSENSE_CLIENT) 없으면
  → 모든 AdSlot이 자동으로 return null
  → 사이트 어디에도 회색 광고 박스 X
  → 깔끔한 UX로 AdSense 승인 신청 가능

승인 후:
- 환경변수만 추가하면 자동으로 광고 표시
- 39곳의 AdSlot이 한 번에 활성화
