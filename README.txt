============================================================
8가지 시나리오 패턴 (박 대표님 6가지 + 추가 2개)
============================================================

박 대표님 6가지 (그대로):
🤔 호기심 자극형      (curiosity)
   문제 제기 → 단서 제공 → 핵심 공개

📋 단계별 가이드      (tutorial)
   도입 → 1단계 → 2단계 → 마무리

⚖️ 리뷰·비교         (review)
   소개 → 장점 → 단점 → 결론

📖 스토리텔링        (storytelling)
   시작 → 갈등 → 해결 → 교훈

🔢 리스트형          (list)
   인트로 → 1위 → 2위 → 3위 → 정리

💬 Q&A형             (qna)
   질문 → 답변 → 부연 설명

추가 2가지 (박 대표님 docx 노하우 + ViralCases 기반):
⚠️ 실수·후회형        (mistake) ← NEW
   실수 공개 → 원인 → 해결책 → 교훈
   "○○ 시작하기 전 알았으면 좋았을 5가지"

📊 데이터·분석형      (data) ← NEW
   주제 → 데이터 제시 → 인사이트 → 결론
   "실거래가/통계로 본 ○○의 진실"
