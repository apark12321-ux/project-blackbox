이 작업의 핵심 원칙:
1. 박 대표님 매뉴얼 텍스트는 절대 노출 X
2. 알고리즘 ID 와 로직만 일반화하여 코드에 반영

4. 어떤 음악, 채널, 팀, 사이트도 언급 X
5. 박 대표님이 직접 만드신 노하우 = 사이트 차별점
6. 다른 사이트가 따라할 수 없는 알고리즘 = 사업 가치

→ 박 대표님 자산은 코드에 녹아있지만 보이지 않음
→ 사용자에게는 결과만 (자동 보정 + 추천)
→ 사이트는 시니어 타겟 영상에 특별히 강한 도구가 됨
