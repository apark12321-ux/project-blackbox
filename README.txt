노하우 태그 시스템 (스며드는 형태)
============================================================

각 비트마다 자동으로 표시되는 태그:
- 후크 (주황) - 첫 30초 후크 패턴
- 음성SEO (파랑) - 키워드 직접 발음
- 챕터 (초록) - 00:00 시작 + 5~7개
- 댓글유도 (자홍) - 참여 지표 ↑
- 저장유도 (보라) - 저장률 = 가치 신호
- 최종화면 (청록) - 관련 영상 + 구독
- 재생목록 (시안) - 연쇄 시청
- 시각화 (노랑) - 이미지/그래프
- 몰입 강화 (보라)
- 긴장 유지 (자주)
- 클라이맥스 (빨강)
- 만족도 (초록)
- 솔직함 (라임)
- 데이터 (시안)
- 검증 (청록)
- 디테일 (앰버)
- 공감 (핑크)
- 감동 (장미)
- 검색최적화 (파랑)
- 전문성 (인디고)
- 신뢰 (시안)
- 해결책 (초록)
- 분석 (파랑)

→ 호버 시 툴팁으로 의미 설명
→ 별도 박스 없이 비트마다 자연스럽게 표시
→ "노하우가 스며들어 있구나" 인지

인터랙션
============================================================

1. 타임라인 비트 클릭
   → 활성 비트 변경 (인디케이터 빛남)
   → 진행률 바 채워짐
   → 상세 영역 업데이트 (시나리오 + 노하우 태그)

2. 첫 비트 (0:00) 활성 시
   → 자동으로 "💡 음성 SEO 적용 중" 힌트 노출
   → 키워드 발음 가이드

3. 마지막 비트 활성 시
   → "💬 댓글 유도 질문 추천" 노출
   → 분야별 댓글 유도 질문 2개

4. 탭 전환
   - 전체 시나리오: Cinematic 컴포넌트
   - 제목 후보: 3개 카드
   - AI 영상 프롬프트: Cinematic 컴포넌트

5. 다른 시나리오 패턴 전환
   - 클릭 시 같은 키워드, 다른 시나리오 URL 이동
   - 즉시 새로운 영상 구조 + 시나리오 결과
