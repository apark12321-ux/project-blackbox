박 대표님 의도 점검표
============================================================

✅ "케이스 바이 케이스로 모든 결과물 보임"
   → 한 페이지에 영상 미리보기 + 제목 + 시나리오 +
     프롬프트 + 설명 + 해시태그 + 정책 모두 표시

✅ "클릭 횟수 최적화"
   → 진입 시 자동 펼침 (0클릭 시작)
   → 비트 클릭 (인터랙션)
   → 복사 클릭 (필수)
   → 다른 시나리오 클릭 (선택)

✅ "시니어/초보자 친화"
   → 단계 번호 X
   → 진입 메뉴 X
   → 큰 글자 + 밝은 색상
   → 시각적 영상 미리보기

✅ "시각적으로 잘 보이게"
   → 영상 프레임 (시나리오 색상)
   → 타임라인 시각화
   → 비트 인디케이터 (활성 강조)
   → 색상별 노하우 태그

✅ "노하우/알고리즘 반영 느낌"
   → 헤더에 시나리오 패턴 명시
   → 비트마다 노하우 태그 자동 표시
   → 시니어 자동 보정 배지
   → 정책 체크리스트
