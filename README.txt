v18.2 - 메타데이터 생성기 실제 작동 수정 (긴급)
============================================================

박 대표님 지적:
  "메타데이터 생성기라고 해놓고 제대로 나오지도 않네"

어시스턴트 발견 문제:
  /publish 페이지에 키워드가 없으면 → 자동으로 메인으로 리디렉트
  = 메뉴 클릭하면 → 메인으로 돌아옴 → "안 나옴"

수정 내용:
  ✅ /publish 직접 클릭 시 키워드 입력 폼 표시
  ✅ 메인 페이지에 키워드 직접 입력 폼 추가
  ✅ 입력 후 → /publish?keyword=... 이동 → 결과 표시

============================================================
새 동작 흐름
============================================================

[흐름 1] 메인에서 입력
  메인 페이지 도구 섹션
  ↓ 키워드 입력 후 [메타데이터 생성 →]
  /publish?keyword=... 이동
  ↓ generateV650Data() 호출 (박 대표님 자산)
  ↓ 결과 표시
  - 제목 후보 5개
  - 영상 시나리오 (5비트)
  - AI 영상 프롬프트
  - SEO 태그
  - 해시태그
  - 설명란

[흐름 2] /publish 직접 클릭
  메뉴 "메타데이터 생성기" 클릭
  ↓ /publish 이동 (keyword 없음)
  ↓ KeywordInputForm 표시 (NEW)
  - 영상 키워드 입력란
  - 예시 키워드 4개 (클릭하면 자동 입력)
  - 받게 되는 메타데이터 6종 안내
  - 시니어 키워드 자동 인식 안내
  ↓ 키워드 입력 후 [메타데이터 생성 →]
  /publish?keyword=... 이동
  ↓ 결과 표시
