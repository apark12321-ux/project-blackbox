============================================================
변경 내용 (v18.0 → v18.1)
============================================================

[메뉴 이름 변경]
v18.0: [홈] [가이드] [자료 만들기] [소개] [문의]
v18.1: [홈] [가이드] [메타데이터 생성기] [소개] [문의]

이유:
- "자료 만들기" = 모호 (무엇을 만드는지 X)
- "메타데이터 생성기" = 명확 (영상 메타데이터)
- 가이드(읽는 정보) vs 메타데이터 생성기(만드는 도구) 차이 명확

[메인 페이지 - 도구 섹션 추가]
새 섹션 "영상 메타데이터 생성기"
- 가치 제안: "노하우 + 알고리즘 11공식 자동 적용"
- 3가지 특징:
  01. 알고리즘 11공식 자동 적용
  02. 시니어 알고리즘 자동 인식
  03. 한 번에 전체 메타데이터
- CTA: "메타데이터 생성기 사용하기 →"
- "완전 무료 · 회원가입 불필요"

[사이트 소개 섹션 - 정체성 명확화]
"가이드 + 도구" 두 가지 방식 명시
- 가이드: 읽는 노하우 (27편)
- 메타데이터 생성기: 자동 적용 도구
= 두 기능이 서로 보완 관계임을 명시

[about 페이지]
"자료 만들기 도구" → "영상 메타데이터 생성기"
도구의 진짜 가치 설명 (노하우 자동 적용)

[contact 페이지]

FAQ 답변 통일
