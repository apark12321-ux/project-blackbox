★ frontend/app/blog/human-warmth/page.tsx (294줄)

제목: AI 시대, 유튜버가 잃지 말아야 할 인간의 온도
부제: AI는 빠르고 유창하지만 흉내 낼 수 없는 것이 있습니다
글자 수: 2,246자 (애드센스 권장 2,000자+ 충족)
읽는 시간: 7분
카테고리: 채널 운영 (channel) → 알고리즘·노하우로 매핑

목차:
  1. AI가 절대 못 만드는 콘텐츠 3가지
     - 직접 살아낸 경험담
     - 망설임이 담긴 진실
     - 시청자와 같은 시간을 통과한 흔적
  2. AI를 도구로 쓰되 인간성 잃지 않는 법
     - AI에게 맡겨도 OK 5가지 (제목/설명/해시태그/썸네일/대본)
     - AI에게 맡기면 위험 5가지 (경험담/댓글/감사인사/슬픈소식/리뷰)
  3. 시니어 사연 쇼츠가 강한 진짜 이유
     - 시니어 시리즈 카테고리 자연스럽게 홍보
  4. 차가운 기술 시대, 따뜻한 채널의 가치
     - 실천 방법 5가지
  5. 마치며: 망설임이 강력한 무기다
     - AlgoMaker 메시지 (인간 노하우 정보 사이트)
