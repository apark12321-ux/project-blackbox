## 🚨 문제 발생 시

### Q1. 숫자가 여전히 줄어들어요
→ 브라우저 강력 새로고침 (Ctrl+Shift+R)
→ 시크릿 창에서 재확인
→ localStorage 초기화 (DevTools → Application → Clear)

### Q2. /done 페이지가 옛날 버전
→ Vercel 배포 완료까지 2~3분 대기
→ Vercel Deployments에서 녹색 "Ready" 확인

### Q3. 이미지 프롬프트가 안 나옴
→ 이전 플로우(카테고리 → 시나리오)를 다 거쳐서 /done에 도착했는지 확인
→ 직접 /done으로 가면 기본값으로 표시됨
